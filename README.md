# Meme Hero / 小球乱斗

一个以“词条构筑 + 自动战斗”为核心的小球对战原型。玩家为小球选择 3 个词条，形成不同战斗风格，然后挑战预设敌人或本地保存的过往玩家构筑。项目当前重点是验证战斗机制、词条组合、meme 化表现和前端体验闭环。

## 当前玩法

- 自动战斗：玩家完成构筑后，小球会自动移动、攻击、碰撞和释放技能。
- 词条构筑：每个小球固定选择 3 个词条，普通词条可重复或唯一，传说词条最多选择 1 个。
- 基础战斗：包含生命、速度、体型、碰撞伤害、击退、远程弹道、状态效果、召唤物等机制。
- 特殊技能：已接入多种传说词条，例如黑曼巴肘击、哈基米护体、唱跳篮球、我的刀盾、虎哥一眼万年、华强买瓜、神鹰哥黑手等。
- 头像表现：传说词条会覆盖专属头像；普通构筑会从普通头像池中分配小球头像。
- 过往玩家：可以保存、命名、导出和导入构筑，并在过往玩家页挑战本地记录。
- 胜场统计：过往玩家构筑会记录胜场，并按胜场数降序排序。
- 设计者模式：提供面向数值调试的入口，用于调整词条和机制参数。

## 技术栈

- Monorepo：pnpm workspace
- 前端：React 19 + Vite
- 渲染：移动端 DOM/CSS 像素风界面；调试战斗画布使用 PixiJS
- 语言：TypeScript
- 测试：Vitest
- 模拟器：独立 `@ball-brawl/sim` 包，负责战斗状态推进和快照生成

## 项目结构

```text
apps/web/          前端应用
packages/shared/   共享类型与基础配置
packages/content/  词条、敌人、基础数值等内容配置
packages/sim/      战斗模拟器
tools/balance/     数值模拟与平衡测试工具
docs/              需求、设计与阶段文档
```

## 本地运行

安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm dev
```

默认由 Vite 提供本地访问地址，通常是：

```text
http://127.0.0.1:5173/
```

如果端口被占用，Vite 会自动切换到其他端口，请以终端输出为准。

## 常用命令

```bash
pnpm typecheck

pnpm build
pnpm balance
```

## 资源说明

## 当前状态

项目仍处于原型验证阶段，重点是快速迭代玩法机制、构筑体验、战斗表现和数值调试流程。当前版本已经可以完成从选择词条、保存构筑、选择挑战者到自动战斗的基本闭环。
