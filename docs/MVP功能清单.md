# MVP 功能清单

## 1. 文档目的

本文档用于把 PRD 中的需求拆成 MVP 可开发、可验收的功能项。本文档不定义最终技术实现细节，具体类型、目录和系统实现见技术架构、数据模型和战斗模拟设计文档。

## 2. MVP 目标

MVP 目标是做出一个可玩的单机 Demo：

- 玩家可以配置小球词条。
- 玩家可以手动配置双方或挑战预设敌人。
- 小球可以自动战斗并结算胜负。
- 30 个 v0.1 词条可以被加载、选择、执行和观察。
- 战斗表现足够清晰，能看懂主要伤害、状态、召唤和胜负结果。

## 3. 优先级定义

- P0：MVP 必须完成，否则游戏核心不可用。
- P1：MVP 应完成，影响体验或验证效率。
- P2：可延期，不阻塞 MVP 验证。

## 4. 功能清单

### F-001 项目基础框架

优先级：P0

功能说明：

- 建立 TypeScript Web 项目。
- 建立 `apps/web`、`packages/sim`、`packages/content`、`packages/shared` 基础结构。
- 能启动本地开发服务器。

验收标准：

- 本地可以通过开发命令打开页面。
- 页面能显示基础应用壳。
- TypeScript 编译通过。

### F-002 词条库加载

优先级：P0

功能说明：

- 内置 30 个 MVP 词条定义。
- 词条包含 ID、展示名、功能副标题、主类型、多标签、重复规则、描述和数值。
- 支持按主类型展示词条。

验收标准：

- 页面能展示 30 个词条。
- 每个词条展示名称、功能副标题、类型和描述。
- 词条 ID 与展示名分离，展示名后续可改。

### F-003 构筑配置

优先级：P0

功能说明：

- 玩家可为蓝方选择固定 4 个词条。
- 自由对战模式下，玩家也可为红方选择固定 4 个词条。
- 系统校验重复规则。

验收标准：

- 未选满 4 个词条时不能开始战斗，或给出明确提示。
- 不可重复词条不能重复选择。
- 可重复词条允许重复选择。
- 构筑配置可被序列化为数据对象。

### F-004 预设敌人

优先级：P0

功能说明：

- 提供 6 个预设敌人构筑：
  - 碰撞流
  - 吸血生存流
  - 弹道流
  - 召唤流
  - 状态消耗流
  - 后期成长流

验收标准：

- 玩家可在挑战模式中选择任一预设敌人。
- 预设敌人均为 4 词条构筑。
- 预设敌人能正常进入战斗。

### F-005 基础战斗模拟

优先级：P0

功能说明：

- 实现固定步长战斗模拟。
- 实现矩形竞技场。
- 实现小球自动移动、墙体反弹、轻微追敌倾向。
- 实现碰撞伤害、碰撞冷却、击退和主球死亡判负。

验收标准：

- 无词条 vs 无词条能完成一局。
- 相同 seed、相同构筑产生可复现结果。
- 主球死亡后能生成结算结果。

### F-006 属性类词条

优先级：P0

功能说明：

- 实现 6 个属性类词条：
  - 生命强化
  - 高速移动
  - 巨型球体
  - 小型灵巧
  - 碰撞强化
  - 坚硬外壳

验收标准：

- 词条能正确修改基础属性。
- 百分比加成默认加算。
- UI 或调试信息能看到最终属性变化。

### F-007 碰撞类词条

优先级：P0

功能说明：

- 实现 5 个碰撞类词条：
  - 吸血碰撞
  - 尖刺反伤
  - 重力击退
  - 碰撞爆炸
  - 撞墙蓄力

验收标准：

- 吸血有每秒上限。
- 反伤不触发连锁反伤或吸血。
- 碰撞爆炸有冷却。
- 撞墙蓄力不能贴墙无限刷层。

### F-008 弹道系统与弹道类词条

优先级：P0

功能说明：

- 装备任意弹道词条后启用弱基础远程攻击。
- 多个弹道词条共同修改同一套远程攻击。
- 实现 6 个弹道类词条：
  - 远程核心
  - 霰弹发射
  - 弹射子弹
  - 追踪子弹
  - 穿透子弹
  - 分裂子弹

验收标准：

- 无弹道词条时不发射子弹。
- 有任意弹道词条时发射弱基础子弹。
- 弹射、追踪、穿透、分裂效果可观察。
- 小子弹不继续分裂。

### F-009 召唤系统与召唤类词条

优先级：P0

功能说明：

- 实现分身、分裂体和炮台实体。
- 实现 4 个召唤类词条：
  - 克隆分身
  - 死亡分裂
  - 分身爆炸
  - 自动炮台

验收标准：

- 克隆分身有数量上限。
- 死亡分裂有最大生命代价，每局只触发一次。
- 分裂体全部死亡才判负。
- 炮台有数量上限和持续时间。

### F-010 状态系统与状态类词条

优先级：P0

功能说明：

- 实现燃烧、中毒、减速、脆弱、护盾。
- 燃烧、中毒、减速、脆弱由碰撞和子弹命中触发。
- 护盾周期性触发。

验收标准：

- 同类状态重复命中刷新持续时间，不无限叠层。
- 护盾最多同时存在 1 层。
- 状态效果能在战斗中被视觉或 HUD 反馈。

### F-011 规则类词条

优先级：P0

功能说明：

- 实现 4 个规则类词条：
  - 低血狂暴
  - 击杀成长
  - 时间成长
  - 复活一次

验收标准：

- 低血狂暴每局触发一次。
- 击杀成长有触发上限。
- 时间成长有层数上限。
- 复活一次有最大生命代价和一次性触发限制。

### F-012 PixiJS 战斗渲染

优先级：P0

功能说明：

- 渲染矩形竞技场。
- 渲染小球、召唤物、炮台、子弹。
- 显示小球生命数字。
- 显示基础战斗特效。

验收标准：

- 战斗画面非空。
- 小球、子弹、召唤物位置与模拟状态一致。
- 伤害、治疗、爆炸、护盾、状态至少有基础视觉反馈。

### F-013 战斗 HUD

优先级：P1

功能说明：

- 展示双方名称、生命、装备词条。
- 展示战斗时间。

验收标准：

- 玩家能在战斗中看懂双方构筑。
- 战斗时间实时更新。

### F-014 结算界面

优先级：P0

功能说明：

- 战斗结束后显示胜者、战斗时长、双方剩余生命、双方装备词条。

验收标准：

- 胜负结算稳定出现。
- 可返回配置界面。
- 可再次开始战斗。

### F-015 本地构筑保存

优先级：P1

功能说明：

- 支持保存当前构筑到本地。
- 支持从本地读取构筑。

验收标准：

- 刷新页面后仍可读取保存构筑。
- 存储结构包含版本号。

### F-016 批量模拟工具

优先级：P1

功能说明：

- 提供命令行工具运行构筑 A vs 构筑 B 多局模拟。
- 输出胜率、平均战斗时长、平均剩余生命。

验收标准：

- 可对任意两个构筑运行至少 100 局模拟。
- 输出结果可用于平衡分析。

### F-017 测试

优先级：P0

功能说明：

- 为战斗核心和词条规则添加单元测试。
- 为页面主流程添加 Playwright 冒烟测试。

验收标准：

- 基础伤害、碰撞冷却、吸血上限、召唤上限、复活、死亡分裂等关键逻辑有测试。
- 浏览器能完成选择词条、开始战斗、出现结算的流程测试。

## 5. MVP 不包含

- 实时好友联机。
- 擂台战服务器。
- 账号系统。
- 数据库。
- 排行榜。
- 词条稀有度。
- 长线养成。
- 复杂皮肤系统。
- 复杂录像系统。

## 6. MVP 验收总标准

MVP 完成时应满足：

- 可以在浏览器中完整游玩一局。
- 可以自由配置双方或挑战预设敌人。
- 30 个词条全部可选择并能影响战斗。
- 战斗可自动结束并结算。
- 无词条、属性流、碰撞流、弹道流、召唤流、状态流、成长流都能被观察到。
- 关键逻辑有测试覆盖。
